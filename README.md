# AI-Based Adaptive Traffic Signal Control

An AI-based adaptive traffic signal control system that uses Reinforcement Learning to optimize traffic flow and reduce congestion.

## Technologies Used

- Python
- Reinforcement Learning
- Multi-Agent Reinforcement Learning
- SUMO
- TraCI
- Streamlit

## Project Overview

This project uses reinforcement learning to dynamically control traffic signals based on real-time traffic conditions.

The system interacts with a SUMO traffic simulation through the TraCI API and learns optimal signal-control policies to improve traffic flow.

## Key Features

- Adaptive traffic signal control
- Reinforcement Learning
- Multi-Agent Reinforcement Learning
- SUMO traffic simulation
- TraCI integration
- Traffic optimization
- Visualization using Streamlit
